# **App Name**: BORDJ STEEL

## Core Features:

- Navbar: A full-width, sticky navigation bar at the top with a logo (BORDJ STEEL), menu items (Home, About, Services, Portfolio, Approvals, Clients, Contact) and a language toggle.
- Hero Banner: A full viewport height banner with a background image, semi-transparent dark overlay, centered headline, and subheading.
- Vision & Mission: Two side-by-side cards with headings and body text, designed to fade in as they come into view.
- Facilities List: A vertical list of cards, each with a section title, descriptive text, and a placeholder image.
- Project Portfolio: A responsive grid of project thumbnails with a subtle zoom and drop shadow effect on hover.
- Certifications: A long list of certifications split into two columns, each styled with a heading and subtitle, set to fade in upon scrolling.
- Contact Form: A two-column layout with contact info on the left and a contact form on the right, designed to fade in when revealed.
- NAVBAR: Full-width, sticky at top.
- NAVBAR Menu: Menu items horizontally: Home, About, Services, Portfolio, Approvals, Clients, Contact.
- Language Toggle: Language toggle button on the right.
- Navbar Transition: Transparent background, transitions to solid on scroll.
- Hero Banner Display: Full viewport height banner with background image.
- Hero Banner Overlay: Semi-transparent dark overlay.
- Hero Banner Text: Centered headline (large), subheading (numeric counter style).
- Hero Banner Animation: Fade-in or zoom-in on page load animation.
- Vision & Mission Display: Two side-by-side cards, each with heading and body text.
- Vision & Mission Animation: Appear with scroll-triggered fade-in effect (staggered).
- Facilities List Display: Vertical list or cards, each containing: • Section title • Descriptive text • Placeholder image or icon.
- Facilities List Animation: Slide-up animation when scrolled into view.
- Project Portfolio Grid: Responsive grid of project thumbnails with overlay.
- Project Portfolio Hover: On hover: subtle image zoom and drop shadow.
- Project Portfolio Animation: Container fades in on reveal.
- Approvals Display: Long list split into two columns.
- Approval Style: Each entry styled as heading + subtitle.
- Approval Animation: Fade-in when section enters viewport.
- Client Logos Display: Grid or auto-scrolling carousel of logos (blank placeholders).
- Client Logos Animation: Logos fade or scale in sequentially.
- Contact Section Layout: Two-column layout: • Left: contact info placeholders (address, phone, email) • Right: Contact form with styled inputs (Name, Email, Message, Submit).
- Contact Submit Button: Submit button accent color.
- Contact Animation: Fade-in reveal.
- Footer Layout: Full-width footer with logo placeholder, site links, and copyright.
- Footer Animation: Static or minimal animation.

## Style Guidelines:

- Steel Blue (#1E3A5F) evokes reliability, rigor, and trust. Use for titles and headings.
- Light Gray (#D9D9D9) for soft backgrounds or secondary areas.
- Pure White (#FFFFFF) to balance visual compositions and provide clarity. Use for main background. Clear text, neutral backgrounds.
- Dark Gray (#4B4B4B) for a neutral and soft touch that balances visual compositions without attracting attention. Creates a sense of order, clarity, and lightness.
- Industrial Red (#C1272D) for action buttons, elements to highlight.
- #1A1A1A for simple backgrounds, premium frames, button hover.
- 'Montserrat', modern and geometric, transmits reliability and industrial rigor. Use for titles, headers, important visual elements.
- 'Roboto', simple, clear, and very readable. Perfect for long texts or descriptions. Use for paragraphs, captions, secondary content.
- Implemented via Intersection Observer for elements like cards, portfolio items, and lists (fadeIn, slideUp).
- Include hover transitions for buttons and project items, utilizing Tailwind CSS utilities.
- Use a responsive grid layout for project thumbnails, client logos, and the contact section to ensure adaptability across various screen sizes.
- The navbar should transition from a transparent to a solid background on scroll, enhancing readability, with the logo of the company to be displayed in a squared rectangle at the top left and the header section is to be wide enough to fit the logo
- Outline style icons, with red highlights.
